# Mapa Simplificado da Escola

Página web educativa desenvolvida em **HTML5** e **CSS3** que apresenta uma planta baixa esquemática e acessível de uma escola, facilitando a localização de seus principais ambientes.

## Ambientes Apresentados

- 🏫 **Entrada**
- 🏢 **Secretaria**
- 👩‍🏫 **Sala dos Professores**
- 📚 **Sala de Aula**
- 📖 **Biblioteca**
- 🌳 **Pátio**
- 🍽️ **Refeitório**
- 🚻 **Banheiro**

## Recursos de Acessibilidade

- **Identificação redundante:** Nenhum ambiente depende apenas de cor; todos contam com símbolo, nome e etiqueta de setor.
- **Alto contraste e tipografia legível:** Paleta com contraste elevado e espaçamento confortável entre blocos.
- **Navegação por teclado:** Menu estruturado e foco visível (`:focus-visible`).
- **Design Responsivo:** Adaptação automática para telas de celulares e computadores via CSS Grid e `@media`.
